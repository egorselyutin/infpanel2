# Информационная панель (InfPanel)

Веб-приложение на базе Streamlit для мониторинга и расчета показателей платежной инфраструктуры по населенным пунктам и районам.

## Особенности
- Интерактивные таблицы с возможностью сортировки.
- Калькулятор прогнозирования ТФД и ФП в реальном времени.
- Оптимизированный интерфейс с поддержкой кастомных шрифтов.
